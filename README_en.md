This repository contains the 7 labs for the Agentic Software Engineering Hackathon course. The labs are organized progressively. Use the links below to open each lab directory.

| Lab | Topic |
| --- | --- |
| [Lab 1](./Lab/Lab01/) | Demo walkthrough on ARC-Bench. |
| [Lab 2](./Lab/Lab02/) | Test-driven software development workflow. |
| [Lab 3](./Lab/Lab03/) | Task-oriented model selection and collaboration. |
| [Lab 4](./Lab/Lab04/) | End-to-end real compilation workflow. |
| [Lab 5](./Lab/Lab05/) | Version rewind and view switching. |
| [Lab 6](./Lab/Lab06/) | Incremental compilation practice. |
| [Lab 7](./Lab/Lab07/) | Interactive compilation and iteration. |
