# Agentic Software Engineering Hackathon

本仓库包含 Agentic Software Engineering Hackathon 课程的 7 个实验（Lab）。各实验按递进方式组织，可从下方链接进入对应目录。

| Lab | 主题简介 |
| --- | --- |
| [Lab 1](./Lab/Lab01/) | ARC-Bench 上的 Demo 演示。 |
| [Lab 2](./Lab/Lab02/) | 测试驱动的软件开发流程。 |
| [Lab 3](./Lab/Lab03/) | 面向任务的模型选择与协作。 |
| [Lab 4](./Lab/Lab04/) | 端到端的真实编译流程。 |
| [Lab 5](./Lab/Lab05/) | 版本回溯与视图切换。 |
| [Lab 6](./Lab/Lab06/) | 增量编译实践。 |
| [Lab 7](./Lab/Lab07/) | 交互式编译与迭代。 |
